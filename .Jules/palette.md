## 2024-05-24 - Data Interpretation & Cognitive Load
**Learning:** Negative index scores (like "Exposure to Bullying") create significant cognitive friction without context, leading to misinterpretation. Additionally, default matplotlib borders and lack of gridlines in data-dense dashboards increase cognitive load for users scanning for insights.
**Action:** Always add contextual tooltips (`help` parameter) to metrics with unintuitive scales (e.g., negative = good), and systematically apply aesthetic decluttering (removing spines, adding subtle gridlines) to all data visualizations.
